Hướng Dẫn Chạy Demo — Hệ Thống Voice AI

rag-legal-assistant · clone-voice-station · voice-lab-example · clone-voice-client

0. Tổng quan hệ thống

rag-legal-assistant gọi clone-voice-station qua HTTP (thông qua SDK clone-voice-client) để lấy tính năng STT/TTS/RVC. voice-lab-example là app demo độc lập, minh hoạ chạy Whisper local so với gọi qua mạng. clone-voice-client không phải service — chỉ là thư viện Python được import bên trong 2 app kia.

8000 rag-legal-assistant

RAG trợ lý pháp lý (FastAPI). Gọi clone-voice-station để có mic input + đọc giọng.

8090 clone-voice-station

Service STT/TTS/RVC độc lập, đa client, có manager dashboard.

8091 Local RVC Worker

Cache model RVC trong RAM cho clone-voice-station — tăng tốc lần đọc thứ 2 trở đi (~0.5–5s so với ~65s lần đầu).

8091 voice-lab-example

App demo độc lập — trùng port với Local RVC Worker, không chạy đồng thời cả hai.

Lưu ý port Local RVC Worker và voice-lab-example đều mặc định port 8091 nhưng không liên quan nhau. Không bật cả hai cùng lúc trong một buổi demo trừ khi đã đổi port một trong hai.

1. Cấu trúc thư mục bắt buộc

4 thư mục phải nằm cùng cấp (anh em):

D:\hoc\project\
├── clone-voice-station\
├── clone-voice-client\      ← thư viện dùng chung, KHÔNG tự chạy, không có app.py
├── rag-legal-assistant\
└── voice-lab-example\

clone-voice-client không cần tự pip install — rag-legal-assistant/requirements.txt và voice-lab-example/requirements.txt đều có dòng -e ../clone-voice-client[local], tự cài khi chạy pip install -r requirements.txt, miễn là thư mục nằm đúng vị trí tương đối. Thiếu thư mục này thì cả 2 app đều không cài được.

6. Demo công khai qua ngrok

Mỗi app runnable (clone-voice-station, rag-legal-assistant, voice-lab-example) có sẵn start_ngrok.py riêng, lộ đúng port của app đó.

Bước 1 — Lộ clone-voice-station ra ngoài

cd clone-voice-station
set NGROK_AUTHTOKEN=your_token
python start_ngrok.py

In ra URL công khai dạng https://xxxx.ngrok-free.app. Giữ cửa sổ này chạy — tunnel tắt khi đóng.

Bước 2 — Trỏ rag-legal-assistant / voice-lab-example vào URL đó

Cách mới (khuyến nghị — không cần restart app):

  • rag-legal-assistant: đăng nhập admin → "Quản lý mô hình giọng nói" → ô "Kết nối máy chủ giọng nói" → dán URL ngrok → Lưu.
  • voice-lab-example: mở http://127.0.0.1:8091/settings (không cần đăng nhập) → dán URL → Lưu.

Cách cũ (cần restart app):

set VOICE_STATION_URL=https://xxxx.ngrok-free.app
python app.py

Bước 3 (tuỳ chọn) — Lộ luôn giao diện app ra ngoài

cd rag-legal-assistant   (hoặc voice-lab-example)
set NGROK_AUTHTOKEN=your_token
python start_ngrok.py
Cảnh báo bảo mật Authtoken cũ từng bị hardcode trong start_ngrok.py và đã lọt vào lịch sử git (đã push lên GitHub). Phải revoke/rotate token đó tại dashboard.ngrok.com/tunnels/authtokens — xoá khỏi file hiện tại không đủ vì lịch sử git vẫn còn token cũ.

Mỗi start_ngrok.py cần NGROK_AUTHTOKEN riêng (hoặc dùng chung 1 token nếu gói ngrok cho phép nhiều tunnel). URL ngrok free đổi mỗi lần restart — phải lặp lại Bước 2. clone-voice-client không bao giờ cần tunnel riêng — nó không phải service.

Backend RVC/PhoWhisper trên Colab (tuỳ chọn, thay máy local)

Chạy colab/voice_server.ipynb trên Google Colab — notebook tự tải cloudflared và mở tunnel, in ra URL (khác cơ chế ngrok ở trên). Dán URL đó vào clone-voice-station: đăng nhập http://127.0.0.1:8090/login → mục "Kết nối RVC (Colab)" → Endpoint URL → Lưu endpoint.

Lưu ý Colab Không dừng/restart runtime khi đang dùng — cloudflared sẽ đổi URL mới. Tunnel free hết hạn sau vài giờ, phải chạy lại notebook + dán lại URL.

7. Xử lý lỗi thường gặp

start_all.bat "thoát ra quá nhanh"

Thường do port 8000/8090/8091 đã bị process khác chiếm sẵn (VD chạy tay từ trước). Kiểm tra:

netstat -ano | findstr ":8000 :8090 :8091"

Nếu thấy dòng "LISTENING", lấy PID (cột cuối) rồi tắt:

taskkill /F /PID <số_PID>

Cửa sổ Local RVC Worker / Clone Voice Station đóng ngay

Mở lại bằng tay (mục 4) để đọc lỗi trực tiếp thay vì qua start_all.bat.

Kiểm tra rvc_endpoint đang trỏ đúng chưa

cd /d D:\hoc\project\clone-voice-station
python -c "from database.database import get_setting; print(get_setting('rvc_endpoint'))"

Phải là http://127.0.0.1:8091 khi dùng Local RVC Worker, hoặc URL cloudflared khi dùng Colab.

Chi tiết từng tính năng: xem terminal.txt trong từng thư mục project, và HUONG_DAN_DEMO.md của mỗi project (HUONG_DAN_CHAY_TOAN_HE_THONG.md, nguồn Markdown của trang này, nằm cùng thư mục).
